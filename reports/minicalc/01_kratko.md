# MiniCalc — коротко (6 ноября 2026)

Ветка: `claude/funny-turing-6w9baw` · код: `minicalc/` · подробности: `02_podrobno.md` · визуально: `analysis.html`

## 1. Что это
Калькулятор с окном (GUI) для **Windows, Linux, macOS**. Android не делали.
Язык: **C** (общее ядро) + тонкий слой под каждую ОС. Для macOS этот слой на Objective-C.

## 2. Статус по ОС
| ОС | Собирается | Запускался | RAM | Итог |
|---|---|---|---|---|
| Linux | да | да, в Xvfb (виртуальный дисплей): клики, клавиши, история | **2.6 МБ** RSS | ✅ готово |
| Windows | локально да (54–73 КБ, только системные DLL) | да, в Wine (эмулятор) | не мерил на настоящей Windows | ⚠️ сборка в CI красная (1 строка фикса) |
| macOS | да, в CI GitHub | да, 4 с в CI | **16 МБ** (лимит 5 не выполнен) | ⚠️ работает, но вид окна не проверен |

## 3. Что сделано
- Калькулятор: `+ − × ÷ %`, скобки, приоритет операций, предпросмотр результата.
- **История на 15 записей** хранится на диске и переживает перезапуск. Клик по записи вставляет её результат.
- 33 юнит-теста ядра, все проходят.
- CI (GitHub Actions) под 3 ОС с замером памяти.
- Zig 0.17.1 скачан, контрольная сумма сверена. Проверил: собирает Windows, Linux и macOS прямо с Linux.

## 4. Что НЕ работает / не сделано
1. CI: Windows-сборка падает: старый MinGW не знает `WM_DPICHANGED`. Фикс — одна строка, не внесён (вы прервали).
2. macOS: 16 МБ RAM. Любое Cocoa-окно занимает минимум ~10–20 МБ.
3. **Zig 0.17.1 как единая сборка** (`build.zig`) ещё не написан, только проверены возможности.
4. На настоящих Windows и Mac окно своими глазами не смотрели.

## 5. Что дальше (по порядку)
1. Внести фикс `WM_DPICHANGED` → CI зелёный.
2. Написать `build.zig`: одна команда `zig build` собирает все 3 ОС.
3. Проверить на живых Windows и Mac.
4. Решить по macOS: принять ~16 МБ или менять подход.
