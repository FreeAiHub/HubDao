# Алгоритм ежедневной активности HubDao

Цель: каждый день вносить в репозиторий **реальные** правки по проектам и держать видимую активность на GitHub.
Правило: никаких пустых коммитов и накрутки — только настоящий прогресс или заметки (статус, решения, TODO, логи).

## Проекты
Каждый проект — файл `projects/<имя>.md` (статус, цель, ближайшие шаги, ссылки).
Стартовый набор: `crowhub-studio`, `farmsite`, `hubdao`. Новые проекты добавляются по шаблону `projects/_template.md`.

## Ежедневный алгоритм (запускается задачей по расписанию)
1. `git checkout main && git pull origin main`.
2. Выбрать проект дня по кругу: `scripts/pick_project.sh` (ротация по номеру дня в году).
3. Открыть `projects/<проект>.md`, обновить: статус, что сделано вчера, 1–3 следующих шага.
4. Добавить запись в `logs/YYYY-MM.md`: дата, проект, что изменено, ссылка на коммит/результат.
5. Если по проекту есть реальная работа (код, тексты, шаблоны) — внести её в соответствующую папку.
6. Раз в неделю (понедельник): сводка в `logs/weekly/YYYY-Www.md` — что сделано по всем проектам.
7. Коммит: `docs(<проект>): ежедневное обновление YYYY-MM-DD`, затем `git push origin main`.
8. Если не было ни одной содержательной правки — не коммитить, записать причину в отчёт.
9. Итог одним сообщением: проект, что изменено, ссылка на коммит.

## Критерии готовности дня
- Есть минимум один коммит в `main` с содержательным изменением.
- Лог за день заполнен.
- Секреты не попали в репозиторий (только `.env`, в `.gitignore`).
