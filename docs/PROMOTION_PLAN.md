# План продвижения: FreeAiHub · CrowHub Studio · FarmSite (12 недель)

Принцип: только органика. Без ботов, накруток звёзд/подписчиков и маскировки автоматизации — любой контент с помощью ИИ подписывается честно.

## 1. Обзор
- **Название:** «Открытая лаборатория» — AI, автоматизация и сайты для малого бизнеса.
- **Главная цель (12 недель):** 5 входящих запросов на сайты (FarmSite) + 2 предложения о сотрудничестве по сложным задачам (энергетика / безопасность / медицина / робототехника).
- **Вторичные:** 100 звёзд суммарно на публичных репозиториях, 150 подписчиков, 3 внешних merged PR.

## 2. Аудитории
1. **Малый бизнес Португалии** (нет сайта или устарел) — боль: нет клиентов онлайн, нет времени. Каналы: Google Maps, Telegram-группы, WhatsApp, местные сообщества.
2. **Инженеры/исследователи** (энергетика, безопасность, медицина, робототехника) — боль: нужны люди для сложных прикладных AI-задач. Каналы: GitHub, LinkedIn, профильные форумы, Hugging Face, конференции.
3. **Open-source сообщество** — ценит полезный код, доки, переводы.

## 3. Сообщения
- **Ядро:** «Строю надёжные AI-системы и сайты, которые работают на результат — от малого бизнеса до сложных инженерных задач».
- Поддержка: (1) сайт за 2 часа, без оплаты до одобрения; (2) открытые шаблоны и пайплайны; (3) 20–30 ч/нед на сложные задачи; (4) прозрачность: что делал человек, что ИИ.
- Доказательства: живые демо-сайты, публичные репозитории, логи в `logs/`, кейсы.

## 6. Что создать
Must: README профиля; README ключевых репо; портфолио и цены; 3 демо-сайта; шаблон письма лида (PT); политика раскрытия ИИ.
Nice: видео-демо 60 сек; open-source шаблон сайта; рассылка.

## 7. Метрики
Главная: 5 входящих запросов за 12 недель.
Вторичные: звёзды, подписчики, просмотры профиля (GitHub Insights), merged PR, отклик лидов (%), конверсия лид→оплата ≥10%, стоимость сайта ≤$5.
Отчёт: раз в неделю в `logs/weekly/`.

## 8. Риски
- **Выгорание/распыление.** Ограничить каналы до 3 в первые 4 недели.
- **Низкое качество ИИ-вкладов.** Проверять диф вручную, предлагать мелкие PR, соблюдать CONTRIBUTING.
- **Репутация и блокировка.** Никакой накрутки, раскрывать использование ИИ, не спамить лидов.
