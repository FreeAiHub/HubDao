# Мост «телефон ↔ компьютер»

Задача: с телефона видеть терминал компьютера и работать с локальным проектом.

## Вариант 1 (рекомендую): Claude Remote Control
Работает и в одной Wi-Fi сети, и через интернет, настраивать сеть не надо.

1. На компьютере открой терминал в папке проекта:
   ```bash
   cd ~/HubDao
   claude remote-control
   ```
2. Открой приложение Claude на телефоне → Claude Code. Сессия с компьютера появится в списке.
3. Пишешь с телефона, а команды выполняются на компьютере, с локальными файлами и скиллами (в том числе HyperFrames).

Альтернатива: Claude Desktop app на компьютере.

## Вариант 2: проверить, что телефон и компьютер видят друг друга в Wi-Fi
1. IP компьютера:
   - macOS: `ipconfig getifaddr en0`
   - Linux: `hostname -I`
   - Windows: `ipconfig` (строка IPv4)
2. На компьютере подними тестовый сервер:
   ```bash
   python3 -m http.server 8000
   ```
3. На телефоне открой в браузере `http://<IP-компьютера>:8000`.
   Видишь список файлов → сеть работает. Не открывается → файрвол или в роутере включена изоляция клиентов.

Так же смотрится превью HyperFrames с телефона: `npx hyperframes preview`, потом `http://<IP>:<порт>`.

## Вариант 3: настоящий терминал с телефона (SSH)
- Компьютер: включи SSH (macOS: Настройки → Общий доступ → Удалённый вход).
- Телефон: Termius (iOS/Android) или Termux (Android) → `ssh user@<IP-компьютера>`.
- Вне дома: Tailscale на обоих устройствах, тогда IP не меняется и порты открывать не надо.
